Tap the prefix, let go, then press the key.
Rows that need no prefix say so.

1

Spaces

one workspace, one repo
fproject picker: fuzzy-find any git repo under ~/personal or ~/projects, newest commit first, and open a workspace rooted there with claude agents running in it (re-picking a project returns you to it)
wworkspace picker
shift+nnew workspace
shift+wrename this workspace
shift+dclose this workspace (asks first)
shift+gnew workspace on a fresh git worktree
Next / previous workspace and prefix+shift+1…9 ship unbound. Set next_workspace or switch_workspace under [keys] if you start keeping more open.

From the shell

the herdr CLI
herdrlaunch, or attach to the session already running
--skillprint the agent control guide. Read it before scripting herdr: the binary is the authority
--default-configevery setting with its default, commented
config checkvalidate config.toml
server reload-configsame as shift+r, from anywhere
agent listevery live agent and its state, as JSON
pane listthe pane tree, as JSON
updateinstall the latest build (channel set preview to ride ahead)
IDs are opaque and never reused: w1 workspace, w1:t1 tab, w1:p1 pane. Read them out of the JSON rather than guessing. Bare herdr opens the TUI, so it is no good for probing.

Panes

splits inside a tab
vsplit to the right (not | as in tmux, which herdr will not take as a key)
-split below
h j k lfocus left / down / up / right
tabcycle to the next pane
shift+tabcycle backwards
zzoom this pane full-screen, again to undo
xclose this pane
shift+prename this pane
bcollapse the sidebar to its narrow rail, again to bring it back
Stock resize mode is prefix+r, which reviewr holds here. Drag a border with the mouse, or give resize_mode another key under [keys].
5

Modes & the rest

navigate, help, detach
gnavigate mode: jump anywhere without the prefix once you are in. hjkl or arrows for panes, ↑↓ for workspaces, 1–9 for tabs, esc to leave
?help: every binding that is live
ssettings
qdetach, and the server keeps every pane running
shift+rreload config.toml in place
shift+ogo to the pane that raised the last notification (moved off o, which now picks files)
A reload reaches everything except how a pane is created: default_shell and new_cwd only apply to panes opened afterwards, and sidebar_start_collapsed waits for a full relaunch.

Tools on a key

all yours, all in config.toml
aa second claude beside this one. Runs fish -C claude, so quitting the agent leaves a shell instead of collapsing the split
shift+athe background claude agents for this repo, in a popup. The sidebar cannot show them: a dispatched session has no pane of its own
dlazygit, in a popup (not g: that is navigate mode)
envim as a full-height sidebar
oopen a file path printed in the agent's output
rreviewr's diff pane, on and off
tyour Pythia slurm queue, split to the right over ssh
prefix+e and prefix+o come from the herdr-nvim plugin; on the nvim side its own keys hang off <leader>h. Add more with herdr plugin install <user/repo>.
7

Agent states

what the sidebar dots mean
workingbusy on your last prompt
blockedherdr recognised an approval or a question on screen
doneit finished while you were looking elsewhere
idleready for input, and you have seen the tab
unknownan agent is there but herdr cannot classify it; never read this as finished
done and idle are the same underlying state; what separates them is whether you have looked. Focusing the tab marks it seen, reading the pane from the CLI does not. Finished and blocked agents also reach macOS notifications, set by [ui.toast] delivery = "system".
Where the stock layout gave way: lazygit left its permanent pane for a popup, because the sidebar already shows branch and status. o moved to shift+o for the file picker; e and r now carry the nvim sidebar and reviewr rather than scrollback editing and resize mode.
